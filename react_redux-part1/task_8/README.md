# Task 11 - Redux is HERE!

This task builds on task 7. The application uses the Redux store for
authentication, notifications and courses. It fetches notifications on mount
and courses when authenticated, and aborts in-flight requests on cleanup.

From `dashboard`, run `npm install` to install dependencies,
`npm test -- --runInBand` to run tests, `npm run lint` to check lint,
and `npm run build` to build the app.
