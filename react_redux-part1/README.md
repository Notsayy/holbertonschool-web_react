# React Redux Part 1

This project introduces state management in React using Redux Toolkit and React-Redux.

## Tasks

- **task_0**: Update project structure to accommodate Redux architecture
- **task_1**: Create and test an authentication slice
- **task_2**: Combine the Redux slices in a root reducer
- **task_3**: Connect the Header authentication controls to the Redux store
- **task_4**: Connect the Footer authentication display to the Redux store
- **task_5**: Connect CourseList to the Redux courses state
- **task_6**: Connect Login to the Redux authentication state
- **task_7**: Connect Notifications to the Redux notifications state
