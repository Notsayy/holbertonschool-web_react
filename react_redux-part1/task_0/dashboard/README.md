# School Dashboard

This React application displays school news and notifications, and lets users
log in to view the available courses.

## Setup

From this directory, install the project dependencies:

```sh
npm install
```

## Available commands

- `npm run dev` starts the Vite development server.
- `npm test -- --runInBand` runs the Jest test suite.
- `npm run build` creates the production build.
- `npm run lint` checks the project with ESLint.
