# React State

This project covers React state management, component interaction, and event handling.

## Tasks

- **task_0**: Adding a local state for notifications (displayDrawer state and handlers)

- **task_2**: App-managed authentication and shared user/logout Context
- **task_3**: Header welcome message and context-based logout
- **task_4**: Footer context consumer and state-managed notifications and courses
